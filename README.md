# 안전지킴이 관리자 웹 기본 골격

참고: 「관리자 페이지 구현 계획 설계」 대화. HTML, CSS, Vanilla JavaScript만 사용합니다. 외부 패키지와 빌드 과정이 없습니다.

## 실행

Node.js가 설치된 PC에서 이 폴더를 터미널로 열고 실행합니다.

```powershell
npm start
```

브라우저에서 http://127.0.0.1:5500 에 접속하고 **샘플 관리자 입장**을 누릅니다. HTML 파일을 직접 더블클릭하면 ES 모듈을 불러올 수 없으므로 서버로 실행합니다. 종료는 터미널에서 Ctrl+C입니다.

검증: `npm test`

## 구현 범위

- 로그인 진입점 및 인증 만료 처리 (기본은 인증 없는 개발용 샘플 입장)
- 대시보드 집계, 작업자 목록·검색·상태 필터·상세
- 이벤트 이력·상태/유형 필터·상세 창
- 긴급 알림·대응 목록, 기기·통신 상태, 처리 기록·보고서 CSV
- 설정(우선 알림 위험도·통신 기준) 및 관리자 목록·추가·역할 변경·사용 중지(샘플 모드)
- 관리자 관리 화면에서 작업자 이름·구역을 입력해 등록하고 작업자 목록에 표시
- 작업자 상세의 생체신호 그래프·NFC 안전확인 재요청·긴급 SOS
- 사이드바 현장 구역별 작업자 수와 날씨·전체 관리자 주의 메시지 화면
- 현장 구역의 예시 전체지도(건물·빨간 제한구역), 접근 자동 경고와 장기 체류 관리자 대응 메시지
- 작업자 직접 위험 신고를 기존 이벤트에 `요청` 상태로 표시하고 확인·해결 처리
- NEW → ACKNOWLEDGED → RESOLVED 처리 및 대응 메모
- 샘플 데이터 localStorage 저장, 로그인 상태 sessionStorage 저장
- 로딩·빈 목록·오류·재시도, null 측정값 표시, 한국 시간 표시
- 15초 주기 재조회와 로그아웃 시 정리

작업자의 안전 상태는 API 응답 값을 표시합니다. 이벤트 해결이 작업자의 정상 상태를 의미하지 않으므로 화면에서 임의로 변경하지 않습니다. 샘플 초기화는 로그아웃 후 로그인 화면에서 가능합니다.

## 구조

```text
index.html                 공통 화면 틀
css/style.css              최소 공통 스타일
js/config.js               샘플/실제 API 설정
js/app.js                  라우팅, 화면 이벤트와 상태 연결
js/domain.js               공통 enum, 상태 전이, 집계
js/api/                    HTTP와 조회/수정 인터페이스
js/services/auth.js        인증 교체 지점
js/services/realtime.js    주기 갱신 및 향후 구독 연결 지점
js/mock/                   샘플 데이터와 저장소
js/components/             공통 표, 배지, 표시 함수
js/pages/                  화면별 렌더링
scripts/serve.mjs           로컬 개발 서버
tests/                     상태 처리·저장·필터 검증
docs/api-contract.md       백엔드 협의용 임시 계약
```

## 다음 연결 작업

1. 팀과 `docs/api-contract.md`의 응답·인증 방식을 확정합니다.
2. `js/config.js`의 주소와 `mock: false`를 설정합니다.
3. 백엔드 인증·CORS를 설정한 뒤 실제 API를 검증합니다.
4. Supabase Auth 사용 시 `services/auth.js`, 토큰 전달은 `api/http.js`를 교체합니다.
5. Supabase Realtime 채널·권한 확정 후 `services/realtime.js`에 구독과 해제를 연결합니다.

실제 백엔드/DB/Realtime 연결은 아직 구현·검증하지 않았습니다. 개발 서버는 로컬 전용입니다. 실서비스 인증·인가와 상태 전이 검증은 반드시 서버에서 수행해야 합니다. 비밀 키나 service_role 키를 프런트에 넣지 않습니다.

긴급 알림 화면은 15초 조회 기반이며 푸시·알림음은 없습니다. 통신 화면은 설정된 기준(기본 지연 5분·오프라인 15분)으로 표시합니다. 샘플에는 휴대폰·워치별 시각이 있으나 실제 API의 기기별 데이터는 아직 협의되지 않았습니다. 처리 기록은 샘플 모드에서 브라우저 저장소에 보관하고 CSV로 내려받을 수 있습니다. 실제 감사 기록은 서버에서 처리자·시각을 기록하고 변경 방지와 접근 권한을 구현해야 합니다.

샘플 관리자 추가는 화면 시연용 목록만 변경하며 로그인 계정을 생성하지 않습니다. 역할 변경·사용 중지도 실제 접근 권한에 영향을 주지 않습니다. 운영 시 관리자 API는 서버에서 총괄 관리자 권한을 확인하고 모든 변경을 감사 기록으로 남겨야 합니다. 작업자 앱에서 실제 위험 신고를 생성·전송하는 기능은 이 웹에 포함되지 않습니다. 서버가 `MANUAL_REPORT` 유형과 `REQUEST` 상태의 이벤트를 보내면 기존 이벤트 화면에서 접수·처리합니다.

현장 구역의 지도는 예시 배치도입니다. 비콘 접근 거리는 최신 측정값(5분 이내)이 기준 2m 이하일 때 자동 경고 기록을 만들고, 실제 내부 진입 시 이벤트 이력에 남깁니다. 내부 체류 10분 이상이면 관리자 대응 메시지를 작성할 수 있습니다. 샘플 모드에서는 실제 작업자 기기로 보내지 않습니다. NFC 확인은 샘플 저장소에서 30분 주기 요청과 3분 미응답 시 자동 SOS 이벤트를 시뮬레이션합니다. 관리자 SOS 버튼도 샘플 이벤트만 만듭니다. 스피커 울림이나 실제 긴급 알림은 연결되지 않았습니다. 날씨의 33°C는 시연용 값이며 현장 위치·기상 API가 연결되기 전까지 실제 날씨가 아닙니다. 전체 관리자 주의 메시지도 샘플 모드에서는 브라우저 기록만 저장합니다.

기간 필터·페이지네이션·차트·관리자별 처리 이력은 후속 확장입니다. 현재 목록 API는 전체 배열을 반환하는 임시 계약이므로 데이터가 늘어나기 전에 페이지네이션과 서버 집계 API를 붙여야 합니다.
